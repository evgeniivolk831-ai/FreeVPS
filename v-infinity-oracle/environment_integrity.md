# V∞ Evaluation Environment Integrity

Promotion requires evidence for:

- exact target/model/version
- exact configuration
- immutable test/evaluator versions
- dependency provenance
- workflow provenance
- execution identity
- artifact hashes where applicable
- reproducible environment description
- absence of unauthorized mutation during evaluation
- temporal binding between target and evidence

Unknown or unverifiable environment properties remain UNKNOWN/BLOCKED.
